# Sentiment Analysis on Reviews

## Project Overview
This project performs sentiment analysis on text reviews and classifies them as Positive or Negative.

## Features
- Text preprocessing
- TF-IDF vectorization
- Machine learning classification
- Predicts sentiment of new reviews

## Technologies Used
- Python
- Pandas
- Scikit-learn
- NLP basics

## How It Works
1. Load review dataset
2. Convert labels into numerical format
3. Transform text using TF-IDF
4. Train a classification model
5. Predict whether a review is positive or negative
